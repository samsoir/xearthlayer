XEarthLayer needs macFUSE

XEarthLayer serves its scenery to X-Plane through a virtual file system, and macOS provides those through macFUSE. macFUSE is a separate download, and it must be turned on in System Settings. Until both are done, xearthlayer run cannot start. XEarthLayer needs macOS 15.4 or later and macFUSE 5.3.3 or later.

If macFUSE is already installed and "macFUSE (local)" is turned on on this Mac, there is nothing more to do here.

1. Install macFUSE

Download the installer from macfuse.io and run it, or with Homebrew run brew install --cask macfuse.

2. Turn on macFUSE

  1. Open System Settings, then General, then Login Items & Extensions.
  2. Under Extensions, click the info button next to File System Extensions.
  3. Turn on "macFUSE (local)". System Settings may list both "macFUSE" and "macFUSE (local)"; XEarthLayer needs "macFUSE (local)".

If X-Plane is on an external drive, also give /usr/libexec/fskitd Full Disk Access under System Settings, then Privacy & Security.

You can do these steps before or after installing XEarthLayer. The macOS guide covers them in more detail.
