XEarthLayer needs macFUSE

XEarthLayer serves its scenery to X-Plane through a virtual file system, and macOS provides those through macFUSE. macFUSE is a separate download, and macOS must be allowed to load it. Until both are done, xearthlayer run cannot start.

If macFUSE is already installed and approved on this Mac, there is nothing more to do here.

1. Install macFUSE

Download the installer from macfuse.io and run it, or with Homebrew run brew install --cask macfuse.

2. Allow kernel extensions (Apple Silicon only)

  1. Shut down the Mac completely.
  2. Press and hold the power button until "Loading startup options" appears, then choose Options to start in Recovery.
  3. Open Utilities, then Startup Security Utility. Select your startup disk, choose Reduced Security, and check "Allow user management of kernel extensions from identified developers".
  4. Restart into macOS.

3. Approve macFUSE

  1. Open System Settings, then Privacy & Security.
  2. Under Security, macOS reports that system software from the developer "Benjamin Fleischer" was blocked. Click Allow. macOS may ask you to enable system extensions first.
  3. Restart when asked.

If the Allow button never appears, run the macFUSE installer again after the Recovery steps.

You can do these steps before or after installing XEarthLayer. The macOS guide covers them in more detail.
