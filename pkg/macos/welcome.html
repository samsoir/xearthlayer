XEarthLayer streams satellite imagery to X-Plane as you fly, through a virtual file system that macFUSE provides.

Before you start, install macFUSE and approve its system extension. On Apple Silicon, kernel extensions must first be allowed in Recovery. The steps are in the macOS guide.

This installs the xearthlayer command in /usr/local/bin. When it finishes, open Terminal and run xearthlayer setup.
