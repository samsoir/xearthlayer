XEarthLayer is installed

The xearthlayer command is in /usr/local/bin. Next:

If macFUSE is installed and approved, open a new Terminal window and run:

xearthlayer setup

Setup finds X-Plane, asks where packages and caches go and which imagery provider to use, and then offers to open the package manager so you can install the regions you fly. The Getting Started guide walks through it.

If not, install macFUSE from macfuse.io, approve it in System Settings, then Privacy & Security, and restart. On Apple Silicon, kernel extensions must first be allowed in Recovery. The Read Me page of this installer lists every step, as does the macOS guide. Then run xearthlayer setup as above.

If xearthlayer --version shows an older version, an earlier copy from Homebrew or a tarball comes first on your PATH. which -a xearthlayer lists every copy.
